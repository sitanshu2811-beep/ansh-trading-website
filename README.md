# Ansh Trading Co. & Services – website

Single-page website for Ansh Trading Co. & Services, a Ministry of External Affairs approved overseas recruitment agency (RA6286986), New Delhi.

- `index.html` – the whole site (styles, scripts, images and flags are built in)
- `.htaccess` – forces HTTPS and enables compression on Hostinger (Apache/LiteSpeed)

## Deploy on Hostinger
hPanel → Websites → Dashboard → Advanced → Git → Continue with GitHub → pick this repo → branch `main` → directory `public_html` → Deploy.
Every push to `main` redeploys automatically.
